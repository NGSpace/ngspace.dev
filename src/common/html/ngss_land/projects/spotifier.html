Add Spotify information to your Hudder HUD!

Set up instructions

  1. Go to Spotify Developer Dashboard.
  2. Press Create App.
  3. Set the Redirect URI to http://127.0.0.1:8888/callback.
  4. Give it any name and description.
  5. Press Save.
  6. Copy Client ID.
  7. Open Spotifier's in-game settings.
  8. Go to Spotify Auth.
  9. Paste your app's Client ID into the Client ID setting.
  10. After saving, an authentication window should open. If not, check the game log for the URL.
  11. Press Agree.
  12. Use Spotifier.

Variables added by Spotifier

Spotifier

  • {has_spotifier} - Will always return true.
  • {spotifier_connected} - Is Spotifier connected and authenticated to Spotify's servers?
  • {spotifier} - The Spotifier object. Do not use it unless you know what you are doing.

Booleans

  • {spotifier_paused} - Is the song paused?
  • {spotifier_shuffle} - Is the playlist shuffled?

Strings

  • {spotifier_repeat} - The repeat status: off, track, or context.
  • {spotifier_track} - The name of the track.
  • {spotifier_album} - The name of the album.
  • {spotifier_album_type} - The type of the album.
  • {spotifier_playlist} - The name of the playlist.

Numbers

  • {spotifier_progress} - The progress of the song, in milliseconds.
  • {spotifier_duration} - The duration of the song, in milliseconds.
  • {spotifier_data_age} - How old the data provided by Spotifier is, in milliseconds.

Arrays

  • {spotifier_artists} - An array of credited artists in the song.
  • {spotifier_queue} - An array of song elements containing track, artists, album, duration, and album_type.
