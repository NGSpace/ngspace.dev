Loops and If Statements


The indentation must be of a consistent type or unexpected issues may occur.

1. If Statements

While this article does imply the existence of an #else statement, it does not exist. Hudder’s inline conditions are designed to be powerful and flexible. However, there are situations where you might want to write more complex logic, or simply prefer the improved readability of a block-based conditional.

For these cases, you can use the #if statement.

Syntax:
To define an #if block, write the keyword followed by the condition, then start a new line and indent the block (similar to Python).

#if [condition] [operations to perform if the condition is true]
Example:
{random = rng(1, 11)} #if random < 5 ;alert, "Random is less than 5!" #if !(random < 5) ;alert, "Random is not less than 5!"

In this example, a random number between 1 and 10 is generated and stored in the variable random.
The first #if checks whether the number is less than 5 — if so, it triggers an alert.
The second #if uses the negation operator ! to check the opposite condition, displaying a different alert if the number is 5 or greater.



2. While Loops

In order to prevent an infinite loop, Hudder will throw an error after 32,768 loop executions. While loops in Hudder allow you to repeatedly execute a block of code as long as a given condition remains true.
They are useful for performing repetitive tasks, waiting for conditions to change, or processing data until a certain state is reached.

Syntax:
To define a while loop, write the keyword #while followed by the condition, then start a new line and indent the block (just like with #if statements).

#while [condition] [operations to perform while the condition is true]

The loop will continue executing the indented block until the condition evaluates to false.


Example:
{random = rng(1, 11)} {loop_count = 0} #while random < 5 {random = rng(1, 11)} {loop_count++} ;alert, "We looped " + loop_count + " times in order to get a random number greater than 5!";

In this example, a random number between 1 and 10 is generated and stored in the variable random.
The #while statement continues looping as long as random is less than 5.
Inside the loop, a new random number is generated each iteration, and loop_count is incremented to track how many times the loop ran.
Once random becomes 5 or greater, the loop ends, and an alert displays how many iterations were required.



3. For Loops

#for loops are only available in Hudder version 8.0.0 and above! Variables declared inside a #for loop are only accessible within the loop’s block. For loops in Hudder are used to iterate over a sequence of values, such as elements in an array or a range of numbers.
They are ideal for performing repeated operations when you know in advance how many times you want to loop.

Syntax:
Hudder supports several forms of the #for statement, depending on what you want to iterate over.


1. Looping through an array
Use this form to iterate over each element in an array.

#for [variable] in [array] [operations using the current element]
Example:
{fruits = ["apple", "banana", "cherry"]} #for fruit in fruits ;alert, "Found fruit: " + fruit;

In this example, the loop assigns each element of the fruits array to the variable fruit on each iteration.
The loop runs three times, displaying an alert for each fruit.



2. Looping with a range (single number)
You can generate a sequence of numbers from 0 up to (but not including) the given number using range().

#for i in range([end]) [operations using i]
Example:
#for i in range(5) ;alert, "Iteration: " + i;

This loop runs five times, with i taking the values 0 through 4.



3. Looping with a range (start and end)
You can also specify both a start and end value using range(start, end).

#for i in range([start], [end]) [operations using i]
Example:
#for i in range(3, 7) ;alert, "Value: " + i;

This loop begins at 3 and runs until (but does not include) 7.
In this case, i takes the values 3, 4, 5, and 6.



4. The break Operation

Although {break} follows the same syntax style as variables (for example, {userid}), it is not a variable and does not behave like one. The {break} operation is used to immediately stop execution. It behaves similarly to break statements found in other programming languages.

Usage:
The {break} operation can be used in several contexts:
  • Inside loops — to exit the loop immediately.
  • Inside functions or methods — to stop execution of the function or method.
  • At the script level — to stop execution of the entire script.

Example 1: Breaking out of a loop
{numbers = [1, 2, 3, 4, 5]} #for n in numbers #if n == 3 {break} ;alert, "Number: " + n;

This example loops through the numbers array and displays each number with an alert.
When n equals 3, the {break} operation stops the loop immediately.
As a result, the alerts for 4 and 5 are never executed.



Example 2: Breaking from a function
#def testBreak {break} ;return, "Not null"; ;alert, "Function returned: " + testBreak();

In this example, the {break} inside the function testBreak stops the function’s execution early.
Because the function ends immediately, the ;return, "Not null"; line is never reached, and the function instead returns null.



Example 3: Breaking script execution
;alert, "Script started!"; {break} ;alert, "This line will never execute.";

When {break} is used outside of any function or loop, it immediately ends the script’s execution.
In this case, only the first alert runs.



5. Example

To see how #if, #while, #for, and {break} can work together, let's look at a practical example.
In this script, we’ll generate a list of random numbers, check them, and stop early if certain conditions are met.

Example:
{numbers = []} {limit = 10} #while length(numbers) < limit {numbers[length(numbers)]=int(rng(1, 11))} ;alert, "Generated numbers: " + numbers; #for n in numbers #if n == 10 ;alert, "Found a 10! Ending early."; {break} #if n < 5 ;alert, "Value " + n + " is less than 5."; #if n >= 5 ;alert, "Value " + n + " is 5 or greater."; ;alert, "Loop complete!";

Here’s what this example does, step by step:

  • 1. It creates an empty array called numbers and sets a limit of 10.
  • 2. A #while loop fills the array with random numbers from 1 to 10 until it contains 10 elements.
  • 3. The #for loop then iterates over each number in numbers.
  • 4. Inside the loop, #if statements check each number:
    • If it’s exactly 10, an alert is shown and {break} stops the loop early.
    • If it’s less than 5, a message notes that it’s below 5.
    • Otherwise, a message notes that it’s 5 or greater.
  • 5. After the loop finishes (or breaks early), a final alert confirms that the script is complete.
