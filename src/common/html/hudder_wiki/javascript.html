JavaScript


This article assumes you already understand basic JavaScript syntax and concepts.

1. Setup

Using JavaScript is a little bit more complicated than using the Hudder language and requires a bit of setting up.

First, you need to enable JavaScript by going into Hudder's settings and toggling "JavaScript enabled".
Second, you need to change the "Compiler type" to "js".
Alternatively, if you want to use both JavaScript and Hudder in your hud, you can use the "run" method and give "js" as the second parameter.


2. Sections and Execution Order

To avoid recompiling on every frame, your script is compiled once. On each update, Hudder invokes functions by their section names and displays the returned values in the corresponding sections.


Section functions
Define exactly one function per section. Whatever the function returns is rendered in that section. function topleft() { return "this will appear in the top left section!"; } function bottomleft() { return "this in the bottom left!"; } function topright() { return "this in the top right!"; } function bottomright() { return "this in the bottom right!"; }
No section
If you need logic that doesn’t correspond to a section, define createElements(). function createElements() { alert("This function does not return a value."); }
Execution order
Hudder calls section functions in the following order each cycle: topleft(); bottomleft(); topright(); bottomright(); createElements();
Resizing sections
Scale the contents of a section by defining a global variable named [section]scale. The default value is 1. var topleftscale = 2; var bottomleftscale = 2; var toprightscale = 2; var bottomrightscale = 2;

3.List of functions and their descriptions:

All parameters are required. If not then they will be. Starting with Hudder 8.0.0, most methods seen in the Method list (Not functions!!!) are available on JavaScript and behave exactly the same. For simplicity and not having to do twice the work, those methods will not show up here.
Function Description Return type Notes
get(String variable) Returns the variable with the given name (ex. fps, key_h). Any Aliases: getVariable, get
getNumber(String variable) Returns the Number system variable with the given name. Number
getString(String variable) Returns the String system variable with the given name. String
getBoolean(String variable) Returns the Boolean system variable with the given name. Boolean
getItem(Number slot) Returns the item in the given slot. ItemStack see also: Item components
set(String variable, Any Object) Sets the variable with the given name to the given object. None
strwidth(String text) Returns the length of the string. Number
compile(String filename, String compilertype) Compiles the file with the specified compilertype (or the javascript compiler if none is specified), returns the compile results and adds the elements created by the file. CompileResult CompileResult has the following properties {String topleft, String bottomleft, String topright, String bottomright, Number topleftscale, Number bottomleftscale, Number toprightscale, Number bottomrightscale}
exists(String filename) Returns true if a file exists in the hudder config dir. Boolean


4. Example

function topleft() { let fps = get("fps"); set("fpsbutbetter", fps+2); return "thy fps+2 is " + get("fpsbutbetter"); }
