Method names are NOT case sensitive Parameters in [] are required, parameters in <> are optional. [Number x] refers to the horizontal position on screen, [Number y] refers to the vertical position on screen. Booleans are either true or false (or conditions), Strings are pieces of text (Strings must be surrounded by quotes) and Number are... well... numbers...

Inventory management

;slot, [Number slot], [Number x], [Number y], <Number scale>, <Boolean showcount>; - draw the item in the provided slot on screen. ;item, [String itemid], [Number x], [Number y], <Number scale>; - draw the item with the provided id on screen. ;hand, [Number x], [Number y], <Number scale>, <Boolean showcount>; - draw the held item on screen. ;helmet, [Number x], [Number y], <Number scale>, <Boolean showcount>; - draw the item in the helmet slot on screen. ;chestplate, [Number x], [Number y], <Number scale>, <Boolean showcount>; - draw the item in the chestplate slot on screen. ;leggings, [Number x], [Number y], <Number scale>, <Boolean showcount>; - draw the item in the leggings slot on screen. ;boots, [Number x], [Number y], <Number scale>, <Boolean showcount>; - draw the item in the boots slot on screen. ;offhand, [Number x], [Number y], <Number scale>, <Boolean showcount>; - draw the item in the offhand slot on screen.

Text Rendering

;text, [Number x], [Number y], [String/Component text], <Number scale>, <HexColor color>, <Boolean shadow>, <Boolean background>, <HexColor bgcolor>, <Number angle>; - Compile and then draw the provided text on screen. ;topleft/topright/bottomleft/bottomright/mute, <Number scale>; - change which section to write to.

Vertex Rendering (See Custom rendering for more info)

;texturevertices, [String filename], [Array vertecies], [Array textures]; - Draws the provided image with the provided vertex and texture array ;colorvertices, [Array vertecies], [HexColor color]; - Draws a shape with the provided vertex array and color ;texturevertices_con, [String filename], [Array vertecies], [Array textures]; - Draws the provided image with the provided vertex and texture array (continous) ;colorvertices_con, [Array vertecies], [HexColor color]; - Draws a shape with the provided vertex array and color (continous)

Other Rendering

;statusbars/xpbar/hotbar/helditemtooltip, [Number x], [Number y]; - Draw the provided Hud element on screen. ;image, [String filename], [Number x], [Number y], [Number width], [Number height]; - Draws the provided Image on screen. ;texture, [String atlas], [String sprite], [Number x], [Number y], [Number width], [Number height]; - Draws the provided (Game) Texture on screen. ;9slicetexture, [String filename], [Number x], [Number y], [Number width], [Number height], [Array slices]; - Draws a texture with 9slice scaling, The slices array is structured [left, right, top, bottom]. ;rectangle, [Number x], [Number y], [Number width], [Number height], [HexColor color]; - Draws a rectangle of the given color on screen. ;gradient, [Number x], [Number y], [Number width], [Number height], [HexColor color1], [HexColor color2]; - Draws a gradient of the given colors on screen. ;horizontal_gradient, [Number x], [Number y], [Number width], [Number height], [HexColor color1], [HexColor color2]; - Draws a gradient of the given colors on screen.

Debugging

;log, [String message]; - Send the provided message in the game console. ;warn, [String message]; - Send the provided message in the game console at warning level. ;error, [String message]; - Send the provided message in the game console at error level. ;alert, [String message]; - Send the provided message in the player's chat. ;throw, [String message]; - Throws an CompileException with the provided message - Please do not use this if you don't know what this means.

Other

;run, [String filename], <Boolean addText (Deprecated, should always be false)>, <String compiler>; - Compile the provided hud with the provided compiler, if "addText" is set to true then it will combine the - text of the compiled hud with the current one, UI Elements always get added. ;writeValue, [String key], [Number/String/Boolean/Character value]; - Writes a value to memory, able to be retrieved across restarts. - The unsafe operations option disables the value type limitations however one should expect type casting issues.
