Functions are NOT case sensitive. Parameters in [] are required; parameters in < > are optional.

Type casting


int([String]) - returns the numeric equivalent of the provided text (ex. "1" returns the number 1, "20" returns the number 20) int([Character]) - returns the ASCII code of the provided character str([Any]) - returns the text equivalent of the provided value (ex. the number 1 returns "1", the boolean true returns "true") char([Number]) - returns the character at the provided ASCII code

Variables


get([String]) - returns the variable with the given name (ex. fps, key_h) (Also accepts getVar) getNumber([String]) - returns the Number variable with the given name getString([String]) - returns the String variable with the given name getBoolean([String]) - returns the Boolean variable with the given name readValue([String]) - Read a value set using writeValue

Math helper functions

Trigonometry

sin([Number]) cos([Number]) tan([Number]) asin([Number]) acos([Number]) atan([Number])

Other

abs([Number]) - returns the positive value of the provided number (ex. abs(1) returns 1, abs(-1) returns 1) floor([Number]) - returns the greatest integer less than or equal to the provided number (ex. floor(7.25) returns 7, floor(8) returns 8, floor(6.9) returns 6) ceiling([Number]) - returns the smallest integer greater than or equal to the provided number (ex. ceiling(7.25) returns 8, ceiling(8) returns 8, ceiling(6.9) returns 7) sqrt([Number]) - returns the square root of the provided number (ex. sqrt(4) returns 2) pow([Number], [Number]) - returns the first number raised to the power of the second (ex. pow(2, 8) returns 256) min([Number], [Number]) - returns the lower of the two provided numbers (ex. min(1, 20) returns 1) max([Number], [Number]) - returns the higher of the two provided numbers (ex. max(1, 20) returns 20) truncate([Number], [Number]) - returns the first number with decimals cut off beyond the number of places provided by the second argument (ex. truncate(1.69, 1) returns 1.6) rng([Number], [Number], ) - returns a random number between the first two numbers; if a third number is provided, it is used as the seed

Misc


length([String]) - returns the length of the provided text (ex. length("Length") returns 6) length([Array]) - returns the length of the provided array (ex. length([1, 3]) returns 2) exists([String]) - returns true if a file named by the provided text exists within Hudder's config folder; otherwise returns false (ex. exists("hud") returns true) strwidth([String]) - returns the rendered width (at scale 1) of the provided text map() - returns a Java HashMap (primarily useful for advanced use cases, only usable when unsafe operations are enabled) array([Number], [Any]) - creates an array of the provided size, filled with the provided value toBinaryString([Number]) - returns the binary value of the provided number in string form (ex. toBinaryString(5) returns "101")

The following functions are deprecated. Please avoid using them as they may be removed in a future update.

Inventory information (Deprecated, see Item components)


itemname([Number]) - returns the name of the item in the provided slot itemdurability([Number]) - returns the durability of the item in the provided slot itemmaxdurability([Number]) - returns the maximum durability of the item in the provided slot itemcount([Number]) - returns the count of items in the provided slot itemmaxcount([Number]) - returns the maximum stack size for the item in the provided slot (ex. if an ender pearl is in the slot it returns 16)

Text manipulation (Deprecated, see Strings)


concat([String], [String]) - returns the combination of the provided texts (ex. concat("1", "2") returns "12") substring([String], [Number], [Number]) - returns the text between the two provided indices (ex. substring("Long text", 1, 4) returns "ong") repeat([String], [Number]) - returns the provided text repeated the requested amount (ex. repeat("Repeat", 2) returns "RepeatRepeat")
